# 📚 نظام إدارة المكتبة

مشروع جماعي بسيط بلغة **Python** لإدارة مكتبة، تم تطويره باستخدام **Git وGitHub** بهدف التدريب على العمل الجماعي، الفروع (Branches)، وطلبات الدمج (Pull Requests)، وحل التعارضات (Merge Conflicts).

## ⚠️ التعامل مع Merge Conflicts

في هذا المشروع يمكن التدريب على إنشاء وحل التعارضات من خلال تعديل ملف مشترك مثل:

```text
README.md
```

أو:

```text
main.py
```

إذا قام شخصان بتعديل نفس الجزء من الملف، قد يظهر تعارض مثل:

```text
<<<<<<< HEAD
التعديل الأول
=======
التعديل الثاني
>>>>>>> feature-branch
```

لحل التعارض:

1. فتح الملف.
2. اختيار التعديل المناسب أو دمج التعديلين.
3. حذف علامات التعارض.
4. حفظ الملف.
5. تنفيذ:

```bash
git add .
git commit -m "Resolve merge conflict"
```
